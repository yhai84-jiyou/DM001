# 帮助手册网站 - 使用手册

> 版本：v1.0  
> 适用对象：管理员、编辑者

---

## 1. 快速入门

### 1.1 系统角色

| 角色 | 权限 | 说明 |
|------|------|------|
| **管理员** (ADMIN) | 全部功能 | 创建用户、管理系统、编辑所有内容 |
| **编辑者** (EDITOR) | 内容编辑 | 编辑文章、管理分类、上传媒体 |
| **读者** | 浏览文档 | 无需登录，直接访问前台 |

### 1.2 首次使用

1. 访问 `http://服务器地址/admin`
2. 系统自动进入**初始化设置**页面
3. 创建管理员账号（设置用户名、密码、显示名称）
4. 登录后开始使用

---

## 2. 管理员操作

### 2.1 用户管理

**创建用户**：
1. 进入「用户管理」页面
2. 点击「新建用户」
3. 填写用户名、显示名称、选择角色（ADMIN/EDITOR）
4. 点击确认 → **系统自动生成随机密码**
5. 将密码告知对方（密码仅显示一次！）

**用户首次登录**：
- 使用管理员提供的密码登录
- 系统强制要求修改密码
- 修改完成后正常使用

**禁用/启用用户**：
- 在用户列表中点击「禁用」
- 被禁用的用户无法登录，但历史操作记录保留
- 可随时重新启用

**重置密码**：
- 管理员可为任何用户重置密码
- 重置后系统生成新的随机密码

### 2.2 查看操作日志

后台「操作日志」页面记录所有人的操作：
- 谁创建了什么文章
- 谁在什么时候发布了哪个版本
- 谁上传了什么文件
- 谁修改了用户权限

支持按**用户**、**操作类型**、**时间范围**筛选。

### 2.3 回收站管理（仅管理员）

- 所有人都可以删除文章（软删除）
- 只有管理员可以操作回收站：
  - **恢复**：将文章恢复到原分类
  - **彻底删除**：永久删除，不可恢复

---

## 3. 分类管理

分类是文档的目录结构，支持多级嵌套。

### 3.1 创建分类

1. 进入「分类管理」页面
2. 点击「新建一级分类」或选中某分类后点击「添加子分类」
3. 填写分类名称和 URL 标识（slug）
4. 可选设置图标

### 3.2 调整顺序

- **拖拽排序**：直接拖拽分类节点调整顺序和层级
- 排序会实时保存

### 3.3 前台可见性

每个分类有「前台可见」开关：
- **关闭**：该分类及其下所有子分类和文章在前台不可见
- **继承规则**：父分类不可见 → 子内容自动隐藏

进入「可见性管理」页面可以一目了然地管理整棵目录树的可见性。

---

## 4. 文章编辑

### 4.1 创建文章

1. 进入「文章管理」→ 点击「新建文章」
2. 选择所属分类
3. **选择编辑器模式**：
   - **富文本**：所见即所得，适合图文混排
   - **Markdown**：左编辑右预览，适合技术文档
4. **注意**：编辑器模式创建后不可更改！

### 4.2 编辑内容

**富文本编辑器**：
- 工具栏支持：标题、加粗、斜体、列表、表格、链接、代码块等
- 插入图片：点击工具栏图片按钮 → 选择本地文件 → 自动上传
- 插入视频：点击视频按钮 → 选择本地视频文件 → 自动上传

**Markdown 编辑器**：
- 左侧输入 Markdown 源码
- 右侧实时预览效果
- 支持标准 Markdown 语法 + 代码高亮

### 4.3 导入文件

- **导入 Word 文档**：选择 .docx 文件，系统自动转换为富文本内容
- **导入 Markdown**：选择 .md 文件，内容加载到 Markdown 编辑器

> 提示：Word 导入后建议检查排版，复杂格式可能需要手动调整。

### 4.4 保存与发布

**保存草稿**：
- 点击「保存」→ 草稿已保存
- **前台不会看到草稿内容！** 前台始终展示上一次发布的版本

**发布文章**：
1. 点击「发布」按钮
2. 弹出发布对话框：
   - **版本号**：如 v1.0、v1.1（必填）
   - **更新说明**：本次更新了什么内容（必填）
3. 确认发布 → 内容同步到前台，读者可以立即看到

**取消发布**：
- 已发布的文章可以取消发布
- 取消后前台不再显示，但文章内容和版本历史保留

### 4.5 编辑已发布文章

1. 打开已发布文章的编辑页
2. 修改内容 → 点击「保存」→ **前台仍然显示旧版本**
3. 满意后点击「发布」→ 填写新版本号和更新说明
4. 前台立即更新为新版本

**核心原则**：编辑 ≠ 发布。保存只更新草稿，发布才同步到前台。

### 4.6 版本历史

1. 在文章编辑页，点击「版本历史」
2. 查看所有发布过的版本列表（版本号、更新说明、发布者、时间）
3. 可以预览任何历史版本的内容
4. **回滚**：将某历史版本的内容加载为新草稿，然后可以修改并重新发布

### 4.7 文章可见性

除了"发布"控制内容是否定版，还有**前台展示开关**：
- 一篇已发布的文章可以选择不在前台展示
- 适用场景：内容已定版但暂时不想公开
- 在文章编辑页或「可见性管理」页面操作

## 5. 可见性管理

「可见性管理」页面提供完整目录树视图：

```
[开] 产品介绍
  [开] 产品概述          已发布 v1.2 · 前台展示
  [关] 内部定价策略       已发布 v1.0 · 前台隐藏
[开] 使用教程
  [开] 基础操作
    [开] 登录注册        已发布 v1.1 · 前台展示
[关] 内部备忘                          <-- 整个文件夹隐藏
  [开] 运维手册          已发布 v2.0
```

- 每个节点旁有开关，切换前台可见性
- 支持批量操作：勾选多个节点，一键设为可见/隐藏
- 分类开关影响其下所有内容

**前台文章可见的条件**（全部满足）：
1. 文章已发布
2. 文章可见开关 = 开
3. 所属分类可见开关 = 开（含所有上级分类）
4. 文章未被删除

---

## 6. 媒体管理

### 6.1 上传文件

- 支持类型：图片（JPG/PNG/GIF/WebP）、视频（MP4/WebM）、PDF
- 大小限制：单文件 < 300MB
- 上传方式：
  - 在文章编辑器中直接上传（推荐）
  - 在「媒体管理」页面单独上传

### 6.2 管理文件

- 查看已上传的所有文件列表
- 图片显示缩略图预览
- 可删除不需要的文件（如文章中有引用会提示警告）

---

## 7. 前台阅读体验

### 7.1 页面布局

- **顶部**：导航栏 + 搜索框
- **左侧**：分类目录树（可展开/折叠）
- **中间**：文章内容
- **右侧**：文章目录（根据标题自动生成）
- **底部**：版本信息和最后更新时间

### 7.2 搜索

- 点击搜索框或按 `Ctrl+K` 打开搜索
- 输入关键词实时搜索
- 结果显示文章标题、匹配片段、所属分类
- 键盘上下箭头选择，回车跳转

### 7.3 图片查看

点击文章中的图片：
- 弹出大图查看器
- 支持：放大/缩小、旋转、拖拽移动、多图翻页

### 7.4 视频播放

点击文章中的视频：
- 内嵌播放器播放
- 支持：播放/暂停、全屏、倍速（0.5x-2x）、进度条拖拽

### 7.5 代码高亮

文章中的代码块自动语法高亮，右上角有复制按钮。

---

## 8. 个人设置

每个用户可以在右上角头像 → 「个人设置」中：
- 修改显示名称
- 修改密码（需验证旧密码）

---

## 9. 注意事项

1. **编辑器模式不可切换**：创建文章时请慎重选择富文本或 Markdown
2. **保存 ≠ 发布**：保存只更新草稿，不影响前台
3. **可见性 ≠ 发布**：已发布文章可以设为前台不可见
4. **密码安全**：首次登录请立即修改初始密码
5. **操作可追溯**：所有操作都有日志记录
